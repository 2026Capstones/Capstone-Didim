# 면접 컨텍스트 데이터 테스트 예시 (JSON)

이 파일은 `POST /analyze-and-feedback` API 테스트 시 `context_data` 항목에 복사해서 붙여넣기 위한 JSON 데이터 모음입니다.

---

## 1. 기술 면접 (Technical Interview)
**목적:** 개발 역량 및 기술적 깊이 검증 테스트

```json
{
  "interview_type": "technical",
  "current_question": "Spring Boot의 동작 원리와 내장 톰캣의 역할에 대해 설명해 보세요.",
  "student_portfolio": "Java 기반 백엔드 개발자 지망생. 프로젝트 3회 수행. JPA 및 QueryDSL 활용 경험 있음.",
  "company_info": "인재상: 기술적 호기심이 강하고 아키텍처 설계를 즐기는 사람. 대규모 트래픽 처리 시스템 구축 중."
}
```

---

## 2. 인성 면접 (Personality Interview)
**목적:** 조직 적합성 및 가치관 검증 테스트

```json
{
  "interview_type": "personality",
  "current_question": "팀 프로젝트 진행 중 팀원과 의견 충돌이 발생했을 때, 어떻게 해결했는지 구체적인 사례를 들어 말씀해 주십시오.",
  "student_portfolio": "학생회 회장 역임. 캡스톤 디자인 팀장으로 참여하여 교내 경진대회 은상 수상.",
  "company_info": "인재상: 협업과 소통을 중시하는 사람. 유연한 조직 문화를 지향함."
}
```

---

## 3. PT/직무 면접 (PT/Job-Specific Interview)
**목적:** 논리적 사고 및 실무 문제 해결 능력 테스트

```json
{
  "interview_type": "personality",
  "current_question": "우리 회사의 신규 서비스 유입자를 20% 늘리기 위한 전략을 제안한다면 어떤 것이 있을까요?",
  "student_portfolio": "데이터 분석 및 마케팅 직무 희망. 파이썬 기반 데이터 전처리 경험 보유.",
  "company_info": "인재상: 데이터 기반의 의사결정을 내리고 실행력이 빠른 사람. 신규 시장 확장 중."
}
```

## 🎬 테스트 영상 촬영용 답변 대본 (Example Scripts)

각 시나리오별로 **약 20초 내외** 분량의 답변 대본입니다. STT가 잘 인식할 수 있도록 또박또박 읽어주세요.

### [Script 1] 기술 면접 답변 (Spring Boot 동작 원리)
> "네, 스프링 부트는 실행 시 내장 톰캣을 포함하여 자바 애플리케이션으로 바로 구동됩니다. 특히 자동 설정 기능을 통해 복잡한 XML 설정 없이도 필요한 빈들을 컨테이너에 등록해줍니다. 덕분에 개발자는 비즈니스 로직에만 더 집중할 수 있어 생산성이 크게 향상되는 장점이 있습니다."

### [Script 2] 인성 면접 답변 (팀 프로젝트 갈등 해결)
> "팀 프로젝트 당시 데이터베이스 설계 방식을 두고 팀원과 의견 차이가 있었습니다. 저는 무작정 제 주장만 펼치기보다, 각 방식의 장단점을 수치화하여 비교표를 만들었습니다. 이를 바탕으로 회의를 진행해 팀원들을 설득했고, 결과적으로 가장 효율적인 결론을 도출하여 은상을 수상할 수 있었습니다."

### [Script 3] PT/직무 면접 답변 (서비스 유입 전략)
> "신규 유입자를 20% 늘리기 위해 저는 데이터 기반의 맞춤형 마케팅을 제안합니다. 기존 사용자들의 이탈 지점을 분석해 보니 회원가입 단계가 너무 복잡했습니다. 이 과정을 간소화하고, MZ세대를 타겟으로 한 숏폼 챌린지를 병행한다면 신규 사용자 유입 목표를 충분히 달성할 수 있다고 확신합니다."

## 💡 사용 방법
1. 위 코드 블록에서 원하는 시나리오의 JSON 내용을 복사합니다.
2. Swagger UI (`http://127.0.0.1:8000/docs`)의 `context_data` 입력 칸에 붙여넣습니다.
3. **각 시나리오에 맞는 대본을 읽으며 영상을 촬영**한 후, 해당 파일을 업로드합니다.
4. **Execute**를 눌러 AI가 내 답변을 잘 인식하고 날카로운 피드백을 주는지 확인합니다.
